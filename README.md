# Domain-Specific LLM Alignment via RLHF

Fine-tuned and aligned a language model for biomedical knowledge extraction using Reinforcement Learning from Human Feedback, with expert-annotated datasets to calibrate responses for target discovery and literature triage (Feb to Apr 2024).

- Prompt-engineering and feedback loop for iterative refinement.
- Conformal prediction and uncertainty quantification to improve factual accuracy, reduce hallucinations, and sharpen scientific retrieval precision.

**Stack:** Python, Hugging Face Transformers, PyTorch, RLHF, Weights & Biases
